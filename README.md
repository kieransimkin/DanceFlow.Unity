# DanceFlow for Unity

**Status: specification and package skeleton — runtime not yet implemented.**

Unity Package Manager package proposal for the DanceFlow beat-synchronised clock, shaders, N-dimensional motion recordings and rigged character animation.

Start with **[docs/00-implementation-plan.md](docs/00-implementation-plan.md)** for architecture, phases, exact contracts, risks, tests and implementation acceptance gates.

The skeleton is not a production runtime. The package currently contains no functional clocks, shaders or animation components.
